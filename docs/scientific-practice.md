# Scientific practice in reactive applications

Reactive controls make exploration fast, but they also make repeated informal
testing easy. Treat slider-driven findings as hypotheses unless the statistical
workflow was designed to account for those decisions.

The application keeps adjusted p-values and effects separate, preserves subject
identity, labels relative composition, and makes QC thresholds user-visible.
It does not infer causality, rerun differential models, or make clinical calls.
